## 복습 질문

**Q1. 스프링 부트의 자동 구성은 어떻게 동작하나?**

<details><summary>답 보기</summary>

클래스패스에 있는 라이브러리와 설정 값을 조건으로 필요한 빈을 자동으로 등록한다. 이 저장소의 Boot 4에서는 자동 구성이 기능별 모듈로 나뉘어, 기능마다 해당 스타터가 필요하다.

</details>

**Q2. Mono와 Flux의 차이는?**

<details><summary>답 보기</summary>

Mono는 0~1개, Flux는 0~N개의 값을 비동기로 내보내는 반응형 타입이다.

</details>

**Q3. 스프링 클라우드 스트림을 쓰는 이유는?**

<details><summary>답 보기</summary>

RabbitMQ·Kafka 같은 메시징 시스템의 차이를 바인더 뒤로 숨기고, 함수(Consumer 등)와 설정만으로 메시지를 주고받게 해 준다.

</details>
