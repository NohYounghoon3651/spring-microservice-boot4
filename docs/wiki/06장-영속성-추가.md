## 학습 목표

- MongoDB(product, recommendation)와 MySQL(review)에 데이터를 저장한다
- MapStruct로 API 모델과 엔티티를 변환한다
- Testcontainers로 실제 데이터베이스를 띄워 영속성 테스트를 작성한다

## 이 장의 기술

`Spring Data MongoDB`, `Spring Data JPA (Hibernate 7)`, `MapStruct`, `Testcontainers 2`

## 실습 코드

- 코드: [`Chapter06`](https://github.com/NohYounghoon3651/spring-microservice-boot4/tree/main/Chapter06)
- Boot 4 변경 내역: [`Chapter06/MIGRATION-BOOT4.md`](https://github.com/NohYounghoon3651/spring-microservice-boot4/blob/main/Chapter06/MIGRATION-BOOT4.md)

## 실행하기

**도커 컴포즈로 실행** (RabbitMQ)

```bash
cd Chapter06
./gradlew build
docker compose build
./test-em-all.bash start stop
```

## 원본(Boot 3.5 / Java 24)과 달라진 점

- Spring Boot 3.5.0 → 4.0.9
- Java 24 → 21
- Gradle 래퍼 8.14 → 8.14.6
- create-projects.bash
- 테스트 스타터 추가 (Boot 4 모듈화)
- `@AutoConfigureWebTestClient` 추가
- 테스트 애너테이션 패키지 변경
- Testcontainers 2.0
- Jackson 2 → Jackson 3
- `catch (IOException)` → `catch (JacksonException)`
- DTO 필드의 `final` 제거
- `server.error.*` → `spring.web.error.*`
- MongoDB 프로퍼티 `spring.data.mongodb.*` → `spring.mongodb.*`
- springdoc-openapi 2.8.6 → 3.0.3
- Dockerfile: 베이스 이미지와 레이어 추출
- `HttpStatus.UNPROCESSABLE_ENTITY` → `UNPROCESSABLE_CONTENT`
