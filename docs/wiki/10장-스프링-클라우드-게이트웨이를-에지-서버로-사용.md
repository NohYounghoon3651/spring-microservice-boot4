## 실행하기

**도커 컴포즈로 실행** (RabbitMQ)

```bash
cd Chapter10
./gradlew build
docker compose build
./test-em-all.bash start stop
```

**Kafka / 파티션 구성**

```bash
COMPOSE_FILE=docker-compose-kafka.yml ./test-em-all.bash start stop
COMPOSE_FILE=docker-compose-partitions.yml ./test-em-all.bash start stop
```

- 테스트 스타터 추가 (Boot 4 모듈화)

- springdoc-openapi 2.8.6 → 3.0.3
- Dockerfile: 베이스 이미지와 레이어 추출
- 헬스 API 패키지 변경

## 복습 질문

**Q1. 게이트웨이 뒤로 서비스를 숨기면 얻는 것은?**

<details><summary>답 보기</summary>

외부 진입점이 하나가 되어 보안·라우팅을 한곳에서 관리하고, 내부 서비스는 외부에 직접 노출되지 않는다.

</details>

**Q2. 라우트의 술어(predicate)와 필터의 차이는?**

<details><summary>답 보기</summary>

술어는 어떤 요청이 그 라우트에 해당하는지 판단하고, 필터는 요청·응답을 바꾸거나(경로 재작성 등) 부가 처리를 한다.

</details>
