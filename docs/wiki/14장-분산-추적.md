## 실행하기

**도커 컴포즈로 실행** (RabbitMQ)

```bash
cd Chapter14
./gradlew build
docker compose build
./test-em-all.bash start stop
```

**Kafka / 파티션 구성**

```bash
COMPOSE_FILE=docker-compose-kafka.yml ./test-em-all.bash start stop
COMPOSE_FILE=docker-compose-partitions.yml ./test-em-all.bash start stop
```

## 복습 질문

**Q1. trace ID와 span ID의 차이는?**

<details><summary>답 보기</summary>

trace ID는 요청 하나가 거치는 전체 흐름을, span ID는 그 안의 개별 작업(서비스 호출 하나 등)을 식별한다.

</details>

**Q2. 메시지로 처리되는 비동기 작업도 같은 추적에 묶이는 이유는?**

<details><summary>답 보기</summary>

메시지 헤더에 추적 컨텍스트가 실려 전달되기 때문이다.

</details>

**Q3. Boot 4에서 Zipkin 엔드포인트를 지정하는 프로퍼티는?**

<details><summary>답 보기</summary>

`management.tracing.export.zipkin.endpoint`.

</details>
