# 위키 생성 스크립트

`docs/wiki/`의 장별 학습 페이지, Home, 사이드바, 푸터를 저장소의 코드에서 만듭니다. 만들어진 페이지는 `main`에 반영될 때 `wiki.yml` 워크플로가 GitHub 위키에 게시합니다.

```bash
python3 tools/wiki/learning.py          # 저장소 어디서 실행해도 됨 (파이썬 3.9 이상, 표준 라이브러리만 사용)
```

| 파일 | 내용 |
|---|---|
| `learning.py` | 장 목록·학습 목표·실행 방법, 페이지 생성. `--issues OUT.json`을 주면 장별 학습 이슈 본문을 JSON으로 출력 |
| `delta.py` | 이전 장 대비 추가·삭제·변경 파일, 새 모듈, 새 의존성 계산 (`git diff --no-index` 사용) |
| `review_qa.py` | 장별 복습 질문과 모범 답안 |

- 직접 쓰는 페이지(`실습-환경-준비`, `Spring-Boot-4-마이그레이션-요약`, `자주-발생하는-문제`, `브랜치-전략`, `Codespaces와-컨테이너-이미지`)는 덮어쓰지 않습니다. 없을 때만 처음 내용을 만듭니다.
- 코드를 고친 PR은 이 스크립트를 실행해 `docs/wiki/` 변경을 함께 커밋해야 합니다. CI의 **Wiki up to date** 검사가 스크립트를 다시 실행해 차이가 있으면 실패합니다.
